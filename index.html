02 — Government / NGO scale

National Farmer Registration System

Digital registry for farmer identity, verification and reporting

A registration platform that replaces paper forms with a verified digital record for every farmer. React front end over an Express API, with hashed credentials, admin role management, email verification and SMS notification so registrations reach people who aren't online.

  • React 19 interface with separated public registration and admin console flows
  • Express 5 + MySQL API with bcrypt hashing, JWT sessions and cascade-safe deletes
  • Email verification via Nodemailer and SMS delivery via Twilio

About

Engineer first. Teacher second. Both make me easier to work with.

I hold a BSc (Hons) in Software Engineering from the University of Lay Adventists of Kigali (UNILAK), Rwanda, and I'm currently reading for an MSc in Information Technology. Over the last five years I've worked both sides of software: building full-stack web and mobile systems, and running the data and MIS work that keeps organisations honest about their results.

Today I'm based in Monrovia, Liberia, where I also serve as an ICT Lecturer and Trainer — teaching software development, computer applications and digital skills, and coordinating faculty events like the UNILAK Computing Faculty 2025 Seminar. Teaching does something useful to an engineer: it forces you to explain your decisions in plain language. Clients get the same benefit — no jargon, no mystery, no "trust me."

I work comfortably across the stack — Laravel, React, Flutter, Node.js, Python and the MySQL schemas underneath — and I care most about the unglamorous parts: does the data hold up, does it still work offline, can the client maintain it after I hand it over.

I ship, then I document. Every project I hand over comes with setup steps, architecture notes and a database map.
I build for real conditions. Patchy networks, low-end devices, users who aren't technical — designed in from the start.
I answer fast. You'll hear back within a day, and you'll always know what stage your project is at.
